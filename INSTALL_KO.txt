대상 탭 자동 클릭 v4.0.0 — 설치 / 업데이트 안내

1. 기존 v3을 사용 중이라면 등록된 URL이 유지되도록 아래 순서로 설치하세요.
   - 먼저 기존 확장프로그램 폴더를 백업합니다.
   - v4 설치 ZIP을 압축 해제합니다.
   - 기존 v3 확장프로그램 폴더의 파일을 v4 파일로 덮어씁니다.
   - Chrome에서 chrome://extensions/ 접속 → 기존 확장프로그램의 '새로고침' 클릭.
   - 확장프로그램 팝업을 열어 URL 목록과 마지막 클릭 기록을 확인합니다.

2. 처음 설치한다면 v4 설치 ZIP의 압축을 해제한 뒤,
   chrome://extensions/ → 개발자 모드 → '압축해제된 확장 프로그램을 로드합니다'
   → manifest.json 파일이 들어 있는 폴더를 선택하세요.

3. 대상 페이지를 등록할 때 사이트 접근 권한을 허용합니다.
   버튼 문구를 실제 텍스트('계속' 또는 'Continue')와 동일하게 입력합니다.
   기본 확인 주기 5시간(1~48시간 변경 가능)을 URL별로 선택합니다.

4. 동작: 처음 등록하면 우선 확인합니다. 누르면 클릭 시각을 기록하고
   그때부터 5시간(설정 시간) 뒤 다시 확인합니다. 아직 버튼이 없다면
   5분 후 재시도합니다. 예약 시 탭이 없으면 자동으로 비활성 탭을 열고
   점검 후 약 2분 뒤 자동 생성된 탭만 닫습니다.

5. 확장이 클릭할 수 있는 건 페이지에서 실제로 보이는 지정 버튼입니다.
   Chrome이 완전히 꺼진 상태나 PC 절전 중에는 예약 확인할 수 없고,
   재실행/절전 복귀 후 재개합니다. 로그인이 풀리거나 인증이 필요한
   경우에는 먼저 수동으로 로그인해 주세요.

주의: 새 경로에 별도 확장프로그램을 설치하면 v3의 로컬 저장 목록이
자동으로 옮겨지지 않습니다. 기존 확장과 새 확장을 동시에 켜 두지 마세요.
